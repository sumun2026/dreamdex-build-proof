CCXT
The CCXT integration is in
alpha
and is not yet published to npm. Install directly from the branch (see below).
CCXT
is an open-source library that provides a unified trading API across 100+ cryptocurrency exchanges. The dreamDEX integration lets you use the same familiar CCXT interface to interact with the DEX.
The source lives on the
add-dreamdex-exchange
branch of Somnia's CCXT fork. TypeScript source and built JavaScript are available; other CCXT-supported languages (Python, PHP, C#, Go) have not yet been generated.
Installation
Install directly from the branch:
bash
npm install github:somnia-chain/ccxt#add-dreamdex-exchange
